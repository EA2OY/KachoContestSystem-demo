¿Qué lenguaje de marcas basado en etiquetas abiertas es ampliamente usado para archivos de configuración? / XML
¿Qué lenguaje de serialización de datos legible por humanos es el estándar en entornos como Ansible y Docker Compose? / YAML
¿Qué base de datos relacional de código abierto utiliza el delfín "Sakila" como su mascota icónica? / MySQL
¿Qué popular base de datos no relacional (NoSQL) almacena datos en documentos similares a JSON? / MongoDB
¿Qué sistema de almacenamiento en memoria basado en clave-valor se usa habitualmente como caché de alta velocidad? / Redis
¿Qué servidor web de código abierto y alto rendimiento es famoso por su arquitectura orientada a eventos? / NGINX
¿Qué servidor web de código abierto histórico de la Apache Software Foundation ha dominado la web durante décadas? / Apache HTTP Server
¿Qué arquitectura de software separa la aplicación en tres capas: Modelo, Vista y Controlador? / Patrón MVC
¿Qué principio de programación busca evitar la repetición de código con las siglas DRY? / Don't Repeat Yourself
¿Qué término informático define un error o fallo en un programa de software? / Bug
¿Cómo se llama el proceso de buscar y corregir errores en el código fuente de un programa? / Depuración (o Debugging)
¿Qué término inglés define al hardware o software obsoleto pero que se mantiene en uso por necesidad? / Legacy
¿Qué tecnología de red móvil de quinta generación ofrece menor latencia y mayores velocidades de transferencia? / 5G
¿Qué sistema global de navegación por satélite es desarrollado y operado por la Unión Europea? / Galileo
¿Qué sistema de posicionamiento satelital es propiedad de las fuerzas armadas de los Estados Unidos? / GPS
¿Qué tipo de ataque de ingeniería social utiliza correos falsos imitando entidades legítimas para robar credenciales? / Phishing
¿Qué método de autenticación requiere dos formas de verificación independientes para acceder a un sistema? / 2FA (o Autenticación de doble factor)
¿Qué dispositivo de hardware filtra el tráfico de red entrante y saliente basándose en reglas de seguridad? / Cortafuegos (Firewall)
¿Qué tecnología crea un túnel privado cifrado sobre una red pública como Internet? / VPN (Virtual Private Network)
¿Qué tipo de cifrado utiliza la misma clave tanto para cifrar como para descifrar la información? / Cifrado simétrico
¿Qué tipo de cifrado utiliza un par de claves, una pública para cifrar y una privada para descifrar? / Cifrado asimétrico (o Clave pública)
¿Qué algoritmo de cifrado asimétrico fue desarrollado en 1977 por Rivest, Shamir y Adleman? / RSA
¿Qué función matemática unidireccional convierte un conjunto de datos de entrada en una cadena fija de caracteres? / Función Hash
¿Qué algoritmo hash de 128 bits ampliamente usado en el pasado se considera hoy obsoleto y no seguro? / MD5
¿Qué familia de funciones hash criptográficas incluye a SHA-256 ampliamente usado en Bitcoin? / SHA-2 (o SHA)
¿Qué tecnología de libro mayor distribuido y descentralizado es la base de las criptomonedas? / Blockchain
¿Qué criptomoneda fue creada en 2009 por la persona o grupo bajo el seudónimo Satoshi Nakamoto? / Bitcoin
¿Cómo se llama la máquina virtual que ejecuta contratos inteligentes en la red Ethereum? / EVM (Ethereum Virtual Machine)
¿Qué tipo de token criptográfico representa un activo digital único e intercambiable en una cadena de bloques? / NFT (Token No Fungible)
¿Qué concepto de red propone una Internet descentralizada construida sobre tecnologías blockchain? / Web3
¿Qué proyecto de red de radio comunitaria global busca conectar sensores IoT mediante la banda ISM? / The Things Network
¿Qué protocolo de mensajería ligero basado en publicación/suscripción es el estándar en IoT? / MQTT
¿Qué tipo de conector coaxial es el más habitual en antenas para equipos de radio de aficionado en VHF/UHF? / PL-259 (o conector SO-239 / N / SMA)
¿Qué parámetro mide la eficiencia del acoplamiento entre la línea de transmisión y la antena en radiofrecuencia? / ROE (Relación de Onda Estacionaria / SWR)
¿Qué tipo de antena consta de dos elementos conductores alineados de igual longitud alimentados en el centro? / Dipolo
¿Qué instrumento de medida especializado permite medir la impedancia y adaptación de antenas en un espectro de frecuencias? / NanoVNA
¿Qué modo digital de comunicación por radio envía mensajes cortos de texto y coordenadas mediante tramas AX.25? / APRS
¿Qué banda de radiofrecuencia de uso libre en 446 MHz no requiere licencia de radioaficionado en Europa? / PMR446
¿Qué tipo de batería basada en litio destaca por su mayor estabilidad térmica y ciclos de vida frente a Li-Po? / LiFePO4 (Litio Ferrofosfato)
¿Qué circuito integrado gestiona el estado de carga, descarga y equilibrado de las celdas en una batería de litio? / BMS (Battery Management System)
¿Qué término define el modo de consumo ultrasilencioso y bajo consumo en microcontroladores para ahorrar energía? / Deep Sleep
¿Qué tipo de pantalla consume energía únicamente cuando cambia la imagen que muestra en pantalla? / Pantalla de tinta electrónica (E-Ink)
¿Qué festival o encuentro informático anual reúne a apasionados de la tecnología, redes y modding durante varios días? / LAN party
